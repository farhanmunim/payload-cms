# Project rules

- Use native Payload CMS features and configuration only — built-in field
  types, globals, collections, access control, hooks, and official
  adapters/plugins. Do not write custom admin components, custom UI, or
  bespoke workarounds when a native Payload feature exists. If a request
  cannot be met with native Payload functionality, say so and propose the
  closest native alternative instead of building custom code.
